# qa/

Generated by the verification pass; heavy artefacts are git-ignored and regenerated with the commands below.

| Folder | What | Regenerate |
|---|---|---|
| `playwright-report/` | HTML report of the smoke suite (Chromium, WebKit, Mobile Safari × RO/RU/EN × every route, forms, API guards, a11y, leaks) | `npm run test:e2e` |
| `test-results/` | Traces and screenshots of failed tests, plus the Telegram mock log of the last run | `npm run test:e2e` |
| `screenshots/` | Full-page captures of the home page in each locale at 360, 390, 768, 1024, 1440 and 1920 px (Chromium) | `npm run test:e2e -- tests/screenshots.spec.ts` |
| `lighthouse/` | Lighthouse mobile JSON for `/`, `/ru`, `/en`, `/servicii/ai-seo` (median of three runs) and `summary.json` with the scores that are committed | `npm run lighthouse` |

Both runners start the production build themselves. The Playwright suite uses an isolated in-memory data adapter and never connects to production Supabase. `npm run verify` chains environment checks, content checks, type checking, linting, build, Playwright, and Lighthouse.
